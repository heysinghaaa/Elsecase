# Changelog

All notable changes to Elsecase are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-08-16

### Added

- `AsyncState`, covering idle, loading, refreshing, empty, success, request
  failure, offline, and forbidden states with recovery and live-region behavior.
- `ResponsiveDataExplorer`, covering search, named filters, sorting, pagination,
  selection, bulk actions, URL restoration, desktop tables, and mobile cards.
- `FormWorkflow`, covering Zod validation, server field and form errors, focused
  error summaries, duplicate-submit protection, autosave recovery, unsaved-change
  warnings, and single or multi-step forms.
- Public shadcn registry endpoints and the `@elsecase` namespace convention.
- Deterministic component simulators, API documentation, installation examples,
  Storybook stories, and source links.
- Vitest, Testing Library, axe, Playwright, registry-schema, production-build,
  and Storybook-build quality gates in CI.
