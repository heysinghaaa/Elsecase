# Portfolio entry

## Title

Production UI Registry — Resilient React Components for Real Application States

## Short description

An open-source, shadcn-compatible React registry providing accessible patterns
for asynchronous states, responsive data exploration, form validation, server
failures, recovery workflows, and mobile behavior. Built with Next.js, strict
TypeScript, Storybook, Vitest, axe, and Playwright.

## Contribution

Product direction, visual system, component API design, React implementation,
accessibility behavior, documentation, deterministic examples, registry delivery,
and automated quality gates.

## Deliverables

- Three installable source-registry components.
- Public documentation and interactive failure-state simulators.
- Responsive, keyboard, focus, URL-state, unit, and accessibility coverage.
- Architecture documentation, changelog, technical case study, and release notes.

## Upwork summary

I designed and built Elsecase, an open-source React registry for production UI
workflows beyond the happy path. The release includes an asynchronous state
boundary, a responsive data explorer, and a recoverable form workflow. Components
install as editable source through the shadcn CLI and include keyboard, focus,
mobile, URL-state, unit, accessibility, browser, Storybook, and clean-install
verification. The project demonstrates component-library architecture without
expanding into application-specific authentication or persistence.
