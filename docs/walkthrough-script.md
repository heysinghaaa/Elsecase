# Elsecase v0.1 walkthrough script

Target duration: 75 seconds. Record the deployed site at 1440 × 900, then include
one 390 px mobile pass. Keep browser zoom at 100% and use the script as narration.

## 0–10 seconds — proposition

Open the homepage.

> Elsecase is a shadcn-compatible React registry for the states teams usually
> leave until the end: failed requests, empty data, mobile tables, server form
> conflicts, retries, and recovery.

## 10–24 seconds — catalogue

Scroll across the three component specimens and open AsyncState.

> Version 0.1 contains three focused workflows. Each installs as editable source,
> so the consuming team owns the code instead of adding an Elsecase runtime.

## 24–38 seconds — AsyncState

Change the simulator from loading to refreshing, error, and offline. Use retry.

> AsyncState keeps initial loading separate from background refresh, preserves
> content when appropriate, announces failures, and protects recovery actions.

## 38–53 seconds — data explorer

Open ResponsiveDataExplorer. Search for Grace, filter a role, select a row, then
resize to 390 px.

> The explorer combines search, filters, sorting, pagination, selection, and URL
> restoration. A semantic desktop table becomes an application-defined mobile
> card instead of a squeezed grid.

## 53–68 seconds — form workflow

Open FormWorkflow in multi-step mode. Clear the name, continue to focus the error
summary, then choose the field-conflict outcome and submit.

> FormWorkflow maps client and server errors into one accessible recovery path.
> Values survive failures, duplicate submits are blocked, and autosave failures
> expose a retry.

## 68–75 seconds — close

Show the install command and GitHub link.

> Every state is documented, tested, and installable from elsecase.vercel.app.
