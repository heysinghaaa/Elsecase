# Contributing to Elsecase

Elsecase v0.1 contains three registry workflows. Contributions should improve
those workflows, documentation, accessibility, tests, or the registry toolchain.
New component proposals belong to the post-v0.1 roadmap and should be discussed
before implementation.

## Development workflow

1. Install dependencies with `pnpm install`.
2. Create a focused branch.
3. Add behavior tests alongside implementation changes.
4. Run the complete foundation checks listed in the README.
5. Describe accessibility and responsive behavior in the pull request.

Do not add fabricated adoption numbers, testimonials, logos, or performance
claims to documentation or examples.
